neatlogs' own email got it wrong

neatlogs' daily email for this project said 6.2% of runs failed. We checked all 81: nine had crashed, 11.1%. These were test runs we crashed on purpose, recorded by the released tracing code of neatlogs, Arize and Traceloop without our fixes. The tracing code caused it; the email only added up what it was given. Every run, by its neatlogs ID.

Witness records status, exceptions, stream completion, refusal text, tool names and usage. It never sends prompt or reply text beyond what neatlogs already records. It never raises into the application. Set TRUEUP_WITNESS=0 to turn it off.

How we know

Trueup's offline lab found 32 confirmed trace disagreements and has five locally proven patches. Every patch is a proposal until its upstream project merges it. The build history is preserved by Entire; the business model is in cfo.ai.

The 737 MAX was intended to show an AOA DISAGREE message when two sensor readings differed. Boeing says a software error made it inoperative on most aircraft; the return-to-service update enabled it across the fleet. This analogy does not claim the alert's absence caused either accident. The two accidents killed 346 people.
