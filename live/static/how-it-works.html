How it works

Two readings.
One warning light.

Witness watches what your agent really does, compares it with what neatlogs recorded, and warns you inside neatlogs when they disagree. Then Trueup's agent repairs the tracing code that wrote the wrong record.

Step by step

From a wrong record to a proven fix.

1

Witness watches the real AI traffic

Add two lines to your agent. Witness reads the calls your app makes to the AI provider and notes what really happened: did the call succeed, was the reply cut, did the app raise an error, how many AI calls were made, did a reply come back.

  • It never changes what your app gets back. Measured cost: about 3 microseconds per call.
  • It never sends prompt or reply text beyond what neatlogs already records.
  • Turn it off with TRUEUP_WITNESS=0.
2

It compares that with the neatlogs record

At the end of each run, Witness puts its own reading next to what the tracing code wrote: the status of each AI call, the status of the whole run, the reply, and the number of AI calls.

3

It lights DISAGREE inside neatlogs

When the record says the opposite of what happened, Witness writes a red TRACE DISAGREE step into the same neatlogs record, right under the step that is wrong. A neatlogs detection, "TRACE DISAGREE light", picks it up, so it can drive a neatlogs alert.

  • On real Claude and OpenAI Agents calls it lit up for both crashes Trueup tested, and went out after the fixes: 2 → 0.
  • Across 40 normal real calls it raised 0 false alarms.
4

Trueup's agent fixes the tracing code

A warning tells you something is wrong. Trueup goes further: it finds the line in the tracing code that wrote the wrong record, writes a fix with tests, proves the fix in its lab, and sends it to the people who maintain that code. See every fix →

Where the wrong record comes from

Not the dashboard. The tracing code.

A dashboard adds up what it is given. The record itself is written by tracing code inside your app: neatlogs' own SDK, or code from Arize (OpenInference) and Traceloop (OpenLLMetry). When that code misses a failure, every view built on it misses it too.

A cut Claude reply. When the reply stream broke off, neatlogs' code still closed the AI step as OK. The app had raised an error.

A failed agent run. The OpenAI Agents tracing code set the top step of every run to OK at the end, even when the run had crashed. neatlogs runs Arize's code for this, so one fix repairs the record for both.

A refused answer. When the AI declined to answer, neatlogs' code left the reply text empty.

How Trueup fixes it

A crash-test lab for tracing code.

Car makers crash cars on purpose to see what the instruments report. Trueup does the same for tracing code, then only keeps a fix that survives every check.

1 · The lab

A practice AI server that fails on purpose

It fails in 57 ways: cut replies, errors halfway through, refusals, agents that loop until they give up, tools that raise. Because the server knows exactly what it sent, there is a true answer to check against.

2 · Compare

Every tool, every failure

Each tracing tool runs the same 57 failures. Trueup compares each record with what the server really sent and lists every mismatch.

3 · Checks

Seven rules before anything counts

A mismatch is only confirmed if it shows up twice in fresh runs, on the latest release and the main branch, with the recommended setup, and with a short stand-alone repro. Anything that fails a rule is set aside and kept on file.

4 · Fix

Writes the fix and its test

Trueup's AI agent finds the code that wrote the wrong record, writes a fix, and writes a new test that shows the problem.

5 · Proof

Proves it, or throws it out

The new test must fail before the fix and pass after. The library's full test suite must still pass. A full run of all 57 test failures must show no new mismatch.

6 · Honest record

Failed tries are kept and shown

The Arize fix passed on its third try; the two failed tries are kept next to it. When all three tries fail, Trueup says "not fixed" and offers no patch.

Where it stops today

  • The fixes sent to Arize, Traceloop and neatlogs are under review, not merged yet. "With Trueup's fixes" means proposed fixes.
  • Witness reads OpenAI and Anthropic calls made through their Python SDKs.
  • In the failed agent run, the fixed record marks the AI step ERROR, but without the error details.
  • It has been tested with neatlogs as the dashboard.
