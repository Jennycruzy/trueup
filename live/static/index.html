Add the second sensor

Two lines in your agent. Witness never changes what your app does, never sends prompt or reply text beyond what neatlogs already records, and turns off with TRUEUP_WITNESS=0. Across 40 normal real calls it raised zero false alarms.

import trueup.witness trueup.witness.watch()
What this is, plainly. The cut and the crash are real failures we cause on purpose: a small relay drops the connection halfway through a real Claude reply, and the agent asks the real server for a model it refuses.
